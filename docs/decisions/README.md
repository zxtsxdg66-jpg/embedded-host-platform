# 设计决策

每篇记录一个决定：当时面对什么问题、有哪些选项、为什么选了这一个、实际结果如何。
结果一栏尽量给实测数字；做了之后发现不对、又改回来的，也照实写。

| # | 决定 | 一句话 |
| --- | --- | --- |
| [01](01-simulation-leak.md) | 用真实字节流验证，而不是只信模拟 | 回环通道保留了消息边界，三个缺陷因此只在真实串口上出现 |
| [02](02-model-never-produces-numbers.md) | 语言模型不接触数值 | 模型只能出一个标签或改写一句写好的话，数字和执行权结构上够不着 |
| [03](03-intent-review.md) | 意图识别：规则优先，模型复核指令 | 两个独立判定器一致才执行，不一致就反问 |
| [04](04-action-whitelist.md) | 自然语言能触发哪些动作 | 三条准入性质量出三种结论：放行、只给按钮、认出但拒绝 |
| [05](05-record-in-callback-send-in-poll.md) | 回调里只记录，轮询里才发送 | 在数据回调里下发命令会重入串口，第一版直接把测试进程打崩 |
| [06](06-history-and-cloud.md) | 本地历史与手动上云 | 标准库 SQLite，上云由人触发，没有定时器、后台线程与上传队列 |
| [07](07-pc-as-gateway.md) | PC 自己兼任网关 | 多端接入时，六层代码零改动 |
| [08](08-web-console.md) | 浏览器控制台 | 不做数据大屏；做看得见的串口链路与可追溯的问答 |
