# llm

本地语言模型服务的客户端。

| 文件 | 内容 |
| --- | --- |
| `ollama.py` | `OllamaClient`：本地 Ollama 的**非阻塞**客户端。`submit()` 立即返回，结果由轮询循环 `poll()` 取回；`probe()` 在启动时探测一次服务是否可达 |

- **不阻塞。** 纯 CPU 上一次推理要几秒，任何阻塞调用都会让采集与界面停住那么久。
  不用 `httpx`：它的流式读取同样阻塞调用线程。只用标准库
- **不抛异常。** 服务没装、没启动、超时都是正常状态：问答退回模板答案，而那个答案本来就是对的
- **响应完整之前不交付任何文本。** 截断的半句话可能恰好通过出口检查（数字都对），却把结论截没了
- **流式响应的格式是抓真实字节确认的**（分块传输包着逐行 JSON），测试里回放的就是抓到的字节
- `LlmClient` 协议定义在消费方 `service/assistant/llm_port.py`，本包靠结构匹配满足它，不 import `service`
- 只能在 `application` 或 `scripts/` 中创建

依赖：只有标准库。
